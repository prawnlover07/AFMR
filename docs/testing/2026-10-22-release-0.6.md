# Combined 0.6 verification — October 22, 2026

Includes Gamemode conditions, Fit songs to time window, and per-playlist Play on
trigger alongside the accumulated template, UI and display updates. Gradle,
NeoForge metadata, current installation references and guides use **0.6**.
Historical version references and reports retain their original measurements.

## Measured results

- The combined build passed **450 automated tests**, zero failures/errors.
- The delivered JAR passed **135 isolated in-game assertions**, zero failures,
  using actual Minecraft screen events, integrated-server commands, generated
  WAVs/artwork and the disposable workspace world/profile.
- Gamemode controls and hidden drafts, saved multiple/empty choices, all four
  server-updated modes, and automatic source changes passed. See the earlier
  [gamemode report](2026-10-22-gamemode.md) for component scope.
- Play on trigger saves independently of finish controls. With a five-second
  global buffer, ten-second silence and one-second fade, a server time change to
  tick 14000 began fading before the buffer elapsed, retained the outgoing source
  during fading and started the triggered song within five seconds without the
  silent gap. Stable matching ticks did not restart it; manual Skip retained its gap.
- Time-screen fitting saved correctly. The worker filled a missing generated
  WAV duration (90 seconds); automatic playback started when it fit. A short
  window left that playlist selected and silent, and widening it resumed playback.
  The disposable clock was paused to stabilize these budgets. These checks do not
  establish behavior under every naturally advancing or manually altered clock.
- Screenshots of the gamemode editor, trigger fade/workspace and Time fitting
  control were inspected. Existing workspace, templates, hold confirmation,
  metadata clearing, popup corners, hover help and menu-alpha assertions passed.

Eighteen trigger tests additionally cover normal fade-out/in, initial/silent entry,
fractional and changed buffers, one-time triggering, normal later gaps, independent
finish protection, cancelled entries, manual Skip/preview/override, pause, existing
fades, zero fade, retained-source return, duration-fitting constraints, ineligible
playlists, clones, snapshots and disk persistence. Returning to Automatic during an
already automatic trigger does not cancel its no-gap transition.
