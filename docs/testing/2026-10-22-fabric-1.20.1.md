# Fabric 1.20.1 backport validation — October 22, 2026

Target: AFMR **0.6**, Minecraft **1.20.1**, Fabric Loader **0.19.5**, Fabric API
**0.92.12+1.20.1**. The NeoForge source and its validation remain separate.
The port starts from the current working source, including Unreleased features.

## Measured results

- **639 automated tests passed**, across 62 suites, with no failures/errors/skips.
  Tests run against Minecraft 1.20.1's Gson **2.10**, including playlist sharing's
  strict input validation. Presentation tests were updated for the single card
  style and removal of menu blur; playback semantics are retained.
- **40 disposable native checks passed**, with no failures. A test-only Fabric
  mod creates/reopens a generated singleplayer world, uses quiet synthetic audio,
  saves only in `ports/fabric-1.20.1/run-smoke`, and exits automatically.
- The packaged run loads the actual remapped release JAR from that profile's
  `mods` folder. Loose AFMR classes and external decoder dependencies are excluded
  from the test runtime. The seven bundled fixture variants decode: MP3, OGG,
  FLAC, 24-bit FLAC, PCM WAV, 24-bit WAV and float WAV. This establishes bundled
  class/provider discovery and decoding, not audible quality for all formats.
- Actual OpenAL checks establish local WAV playback, a fixed sample position while
  paused, advancement on the same source after resume, and pause intent retained
  through asynchronous stream attachment. Vanilla soundtrack playback/pause/resume,
  playlist volume reaching native gain, overrides with Automatic off, Next, native
  queued playback and successful-start history also pass.
- Title-screen/world workspaces and Library, Timing, Display, Keys, Inspector,
  Queue/history, Profiles and Conditions pages open/render. Screenshots are saved
  in the disposable profile. Workspace hide/reopen and generated-file import on
  the library worker pass. The native picker DLL loads without opening a dialog.
- Release inspection confirms Java **17/class version 61** for all AFMR classes,
  seven nested decoder libraries, and no NeoForge metadata or smoke-test classes.

Native testing used the development **JDK 25** and Loom's corresponding native
runtime libraries. The shipped mod is compiled with `--release 17`. A standalone
Java 17 game run has not been measured.

## Corrections during the port

The older GUI scissor API needs explicit scaled bounds. Native screenshots caught
blank/clipped list areas; all workspace/list/card clip rectangles now account for
their transforms. Subsequent screenshots show the playlist/library rows correctly.

The native probe initially treated a streaming OpenAL offset as monotonic. Because
processed stream buffers are removed, that offset can wrap. The corrected check
requires the same native source, a playing state, and repeated position changes;
the independent paused-position check still requires the offset to remain fixed.

The test source set initially combined compilation and runtime libraries, putting
an old LWJGL Java JAR before Loom's upgraded natives. Its runtime now uses Loom's
runtime dependencies directly. This was a test-launch configuration error.

The logger parent is held strongly, preserving the current source's suppression
of excessive jaudiotagger WAV-chunk logging across garbage collection.

## Intentional scope changes

The AFMR album-art card is the sole now-playing style. Native/Hybrid toasts,
the newer pause-menu song display, vanilla Music Frequency synchronization and
menu blur are removed. Card preferences and menu opacity remain. Artwork fallback
is a static music note. Minecraft content/catalogs reflect 1.20.1 and installed
mods/resource packs. Native file dialogs use LWJGL Tiny File Dialogs instead of SDL.

The existing singleplayer-only structure and mob-target observations retain their
limits in multiplayer; this port adds no server companion or new synchronization.

## Reproduce and remaining work

With JDK 25 available, from `ports/fabric-1.20.1`:

```powershell
.\gradlew.bat build sourceZip
python testing/prepare_smoke.py
.\gradlew.bat -Psmoke -PpackagedSmoke runClient
```

Inspect `run-smoke/smoke-results.txt` for the result rather than relying only on
the game's process exit code. The smoke mod is excluded from the release JAR.
Raw runtime logs contain local paths/device names and stay ignored. The preserved
evidence is the test's path-free result list.

Physical keyboard/mouse behavior, Explorer dialog interaction/cancellation,
device changes, resource reload, deeper jukebox/combat/structure cases, actual
1.20.1 multiplayer, third-party mod compatibility and large/long-running libraries
still need native testing. The automated scheduler tests do not prove those cases.
