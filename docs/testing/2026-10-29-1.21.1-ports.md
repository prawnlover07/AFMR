# Minecraft 1.21.1 ports — October 29, 2026

Targets: AFMR 1.1.1, Fabric Loader 0.19.5 / Fabric API 0.116.17+1.21.1 and
NeoForge 21.1.265. Both ship Java 21 bytecode and were tested on Java 21.
These are independent additional ports; the original `v1.1.1` tag and release
baseline remain unchanged. No public upload is part of this work.

All final native runs reported zero failures. Decoder cases cover MP3, Vorbis,
FLAC, WAV, 24-bit FLAC/WAV and float WAV, producing signed 16-bit PCM through the
actual production JAR and its nested libraries. The integration pass exercises
native source pause/seek/fades, overrides, queued playback, history, profiles,
repair, sharing, location conditions, shutdown flush and saved-state restoration.
It does not establish prolonged modpack or large-server stability.

Clients ran sequentially in isolated profiles at 60 FPS with VSync off.
NeoForge's early startup window was disabled. Generated assets and fixtures were
used; personal music, foobar playlists/settings, saves and launcher preferences
were preserved. Raw logs/results remain local under `work/porting-2026-10-29`
and each port's ignored `run-*` folders.

## Target differences and packaging

Both use AFMR's card widget; vanilla music toast/frequency and menu blur
integrations are unavailable in this Minecraft version. Loader registration,
typed networking, HUD and sound hooks call each target's APIs directly.

NeoForge's module loader needs the two audio SPI artifacts packaged together,
with merged provider lists and original embedded notices. Decoder discovery
uses the owning Java module layer. Minecraft already supplies JOrbis on this
target, so AFMR does not include a duplicate module. Fabric keeps the original
thirteen separate nested audio/image JARs and ordinary class-loader discovery.
The minimal companions contain server observation/network code and structure
values, with no audio/image libraries or client assets.

Both extracted source archives independently pass `build sourceZip`. Metadata,
Java 21 bytecode, nested-library notices, minimal companion exclusions and source
privacy were audited. Five artifact hashes accompany each client/companion/source
package under `outputs/1.1.1/ports/Fabric-1.21.1` and `NeoForge-1.21.1`. Broader
physical keyboard, third-party codec/modpack and prolonged multiplayer cases
remain field tests in `DEFERRED-TESTING.md`.
