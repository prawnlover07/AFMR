# Forge 1.20.1 port — October 29, 2026

Target: AFMR 1.1.1, Minecraft 1.20.1, Forge 47.4.0, Java 17 shipped bytecode/runtime.
The original 1.1.1 tag and baseline packages remain unchanged. This report covers
the independent additional port, not a public upload or general modpack certification.

## Measured checks

- Full build: 1,011 pure regressions, ten packet/audio components and 20 UI-copy checks.
- Packaged Java 17 client: 16 now-playing shortcut checks, ten transformed-game
  surface-cover fixtures, 49 navigation/transport checks and 24 mute-warning checks.
- Packaged playback/library integration: 83 checks; saved-state restart: 17 checks.
- Packaged decoder discovery: seven cases covering MP3, Vorbis, FLAC, WAV,
  24-bit FLAC/WAV and float WAV, producing signed 16-bit PCM.
- Minimal dedicated companion: 13 headless checks; actual companion connection:
  12 checks; actual vanilla-server fallback: eight checks.

All final runs reported zero failures. Clients ran one at a time in disposable
profiles at 60 FPS with VSync off; Forge's early startup window was disabled.
No personal music, foobar files, saves or launcher preferences were modified.
Logs/results are retained locally under `work/porting-2026-10-29` and this port's
ignored `run-*` directories.

The initial integration run lacked a generated cover-art fixture and failed two
checks; a complete fresh fixture/profile passed all 83. One initial connection
disconnected during login; its cause was not established. The unchanged runtime
passed the subsequent companion and vanilla connections. These observations do
not establish prolonged multiplayer stability.

## Issues corrected during validation

Forge's module loader rejected the audio SPI libraries' shared package. Their
identical shared class and separate provider registrations now live in one
game-layer JAR with original notices preserved. Discovery uses the owning Java
module layer in Minecraft and the ordinary class loader in plain-JVM tests.
This was verified with the actual nested production libraries; a passing JVM
regression alone would not demonstrate packaged audio support.

Minecraft 1.20.1 retains the AFMR card rather than newer vanilla music toast,
frequency or blur integrations. Client initialization stays out of the minimal
dedicated-server companion, which bundles no audio/image libraries or assets.

The extracted source archive independently passes `build sourceZip`. Runtime
metadata, Java 17 bytecode, nested libraries/notices, companion exclusions and
source privacy were audited. Five artifact hashes accompany the client,
companion and source packages under `outputs/1.1.1/ports/Forge-1.20.1`.
Broader modpack,
physical keyboard, large-server and prolonged-session checks remain field tests
in `DEFERRED-TESTING.md`.
