# AFMR 1.1.1 baseline release — October 29, 2026

Animal chose to release the existing two builds with the now-playing hotkey first,
then add the independently tested ports in [PORTING.md](../PORTING.md). The planned
matrix is not a claim that those additional targets already work.

| Numbered check | NeoForge 26.3 | Fabric 1.20.1 |
| --- | ---: | ---: |
| Fresh pure regressions | 1,011 passed | 1,021 passed |
| Packet/audio components | 10 passed | 10 passed |
| Copy compiler checks | 20 passed | 20 passed |
| Packaged hotkey/startup/playback checks | 19 passed | 16 passed |
| Packaged companion headless checks | 13 passed | 13 passed |

All listed checks have zero failures/errors/skips. Native clients ran one at a
time, capped at 60 FPS with VSync off before startup; Fabric ran on Java 17.0.15.
The checks use generated music/artwork and disposable worlds/configuration. The
hotkey reopens each supported style, bypasses the initial popup delay, refreshes
its timer and works during manual music pause without changing audio, queue,
history or cached artwork. AFMR/Minecraft visibility preferences still apply.
See [the feature report](2026-10-29-now-playing-key.md) for exact probe coverage.

Companion JARs differ from the released 1.1 versions only in loader metadata;
all their class payloads are identical. This patch reruns their thirteen headless
service cases each. It does not claim new socket lifecycle coverage: actual
companion/fallback connections are recorded in the [1.1 release report](2026-10-28-release-1.1.md).
No protocol or server behavior changed for the hotkey. Broader modpack, physical
input/device, multiplayer scale and storage cases remain in DEFERRED-TESTING.md.

Both clients and companions have synchronized 1.1.1 metadata. Client bytecode
remains Java 25 / Java 17; the runtime JARs exclude probe/smoke classes. Client
packages include their thirteen bundled-library sources and required notices;
server packages contain only their scoped companion code, license and instructions.
Source archives exclude Git data, caches, personal music/configuration, logs,
worlds and old workspaces, and retain the wrappers/shared authoring inputs.

Local release checkpoint: **v1.1.1**. Distribution ZIPs, direct JARs, source ZIPs
and SHA256SUMS.txt are under ignored **outputs/1.1.1**. Older releases remain intact.
Nothing has been uploaded publicly or sent to anyone. Port implementation starts
after this baseline checkpoint, retaining its tag and artifacts.
