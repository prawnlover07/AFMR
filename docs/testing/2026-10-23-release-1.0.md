# Private 1.0 release verification

October 23, 2026. The author authorized game windows and deferred independent
friend testing until after release. All state-changing tests use disposable
instances and generated audio/images. Personal music, foobar data and game
configurations remain untouched.

## Automated checks and packaging

Both `build sourceZip --offline` commands pass with the final reviewed author copy:
**778 NeoForge / 788 Fabric JUnit tests**, no failures or errors, plus **20 copy
compiler checks per target**. Applicable language entries are 150 / 148.
These tests do not establish native audio or visual results.

AFMR's own code and documentation use MIT, copyright 2026 animal, as explicitly
chosen by the author. `LICENSE` is included in both runtime JARs and source ZIPs;
NeoForge and Fabric metadata identify MIT. The template and bundled components
retain their own notices. Future creator support is optional, without restricted
builds or functionality; no donation service or public hosting was configured.

The final archive audit found upstream dependency JARs without embedded license
files. Packaging now reproduces copyright/license blocks from their exact source
artifacts and carries full GNU Library/Lesser GPL texts. All thirteen original
Maven Central source JARs accompany each private package with coordinates, URLs
and hashes. This changes legal materials, not runtime behavior.
