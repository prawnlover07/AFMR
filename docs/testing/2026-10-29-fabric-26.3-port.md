Build: Java 25, Gradle 9.8.2, Loom 1.19.3, Loader 0.20.1, Fabric API 0.165.0+26.3.
Native clients loaded the packaged AFMR JAR, one client at a time, capped at
60 FPS with VSync off before startup. Profiles, music and artwork were disposable;
no personal game instances or foobar data were modified. Client audio checks use
Minecraft's sound executor to inspect actual OpenAL playback, gain and position.

The shortcut check covers actual registered input-queue dispatch, pause, popup
styles/timing and preserved playback/cache identity. Navigation includes local and
Minecraft-resource seeks, cancellation/buffer collection and real row hit testing.
Mute checks cover music/master zero gain, continued progress, natural completion,
ordinary silence and silent subsequent starts. The feature pass exercises folder
imports, playlist gain, queue/history, profiles, repair, sharing and shutdown;
restart verifies saved configuration without retaining transient playback state.
Screenshots of the workspace, menus and popup styles were inspected.

The optional companion loads without client classes/audio libraries. Self-scoped
observations, target switching/removal, malformed scope/radius and maximum-radius
loaded-only scanning pass headless. Real loopback multiplayer verifies negotiation,
remote bounds/catalog, combat event-start/target retention/loss and separate PvP
state. An unmodified 26.3 server verifies optional-channel fallback and event timeout.

## Harness corrections and limits

Initial feature checks sampled a still-fading native channel and clicked a third
queue row below a two-row viewport. The final harness waits for stable native gain
and reveals its target row before clicking; the final fresh profile passes all 83.
The headless fixture re-requests after Fabric's chunk/entity-load transition, as a
real client periodically does; the final 13 checks pass. These corrections changed
only the test harness, not the production scheduler or gain calculation.

Raw logs/results remain under ignored `work/porting-2026-10-29` and the port's
`run-*` directories. Additional codec, resource-pack, third-party sound-mod,
long-session and large/many-client server combinations remain field coverage.
The independent source archive also passes a fresh standalone build and sourceZip.
Packaged artifact hashes are recorded with the separately prepared port artifacts;
this report does not claim public upload or support for still-planned matrix rows.
