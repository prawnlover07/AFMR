# Mod icon verification — October 29, 2026

The owner's green-note AFMR image is copied unchanged into all ten client
targets and all ten optional companions. The PNG is 512 × 512 pixels; SHA-256:
`9c617b3949f650b316c22f4685ba1de1e2fde045eb3167014bda269104196564`.

Fabric metadata uses `icon`; Forge/NeoForge metadata uses `logoFile`. Each points
to the packaged `icon.png`. The minimal server archives explicitly include that
single branding image alongside server code, metadata and the license.

All ten full builds pass their regression, component and UI-copy checks. The
built twenty runtime JARs were opened and their image bytes compared against the
owner's original; all match. Metadata was parsed as JSON/TOML and its referenced
path checked. The source image was visually inspected. This is packaging
validation, not a separate claim that twenty loader-menu screenshots were taken.

For previously completed targets, production class hashes match their tested
packages. Fabric 1.20.1 has one known earlier difference: six UI-copy identifiers
in `NowPlayingSettingsScreen` changed from the loader-specific `.fabric` suffix
to `.card`. Normalizing only those six constant-pool strings makes the class
identical to the baseline; the author's prose remains unchanged and copy
validation passes. Audio, scheduling, networking and hotkey classes are unchanged.

Version remains 1.1.1 during the port expansion. The original release tag and
previous output packages are preserved; the combined multi-version packages
include the new icon. Unrelated page notes were not included in this change.
