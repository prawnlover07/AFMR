# Gamemode conditions — October 22, 2026

The Gamemode filter supports any selected combination of Survival, Creative,
Adventure and Spectator. It starts disabled, with Survival selected. An enabled
filter with no selections cannot match. All/Any/Not groups, playlist priority,
normal transitions, clones, save snapshots and Inspector use the same predicate.
Manual overrides and previews retain their condition-bypassing behavior.

The runtime reads Minecraft's current client player-mode state, including normal
server updates. A direct enum switch populates the existing context snapshot;
evaluation uses an enum-set lookup without library traversal or new I/O.
The editor keeps its local selections while hidden, and saves on Save & back.

## Measured gamemode verification

- The initial 0.6 gamemode build passed **398 automated tests**, zero failures.
  Twelve new cases cover all four modes, multiple/empty/disabled selections,
  unavailable mode, All/Any/Not groups, normalization, independent clones and
  snapshots, disk persistence, priority/empty fallback, manual overrides, normal
  buffer/fade/silence and Inspector diagnostics. Existing context constructors were
  updated directly; no obsolete constructor or compatibility layer was retained.
- The same packaged JAR passed **120 isolated in-game checks**, zero failures.
  Fifteen new assertions cover editor access, all four controls, hidden drafts,
  saving multiple selections, actual server-driven Survival/Creative/Adventure/
  Spectator changes, source-playlist changes, filter-off retention, and saved
  empty selections falling through to another playlist.
- The new editor screenshot was inspected in the 854×480 workspace profile.
  Generated quiet WAVs, a generated cover image and a disposable world/profile
  supplied fixtures; personal music, foobar state and personal game profiles
  were untouched. The test-only helper is not bundled in the mod.
- An initial native run passed every gamemode check but missed the first delayed
  tooltip during startup (118 passed / 2 failed). Adding one settling interval to
  that fixture, without removing assertions or changing the mod, produced the
  120/0 result.
