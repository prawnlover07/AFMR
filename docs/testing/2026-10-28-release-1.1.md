release notes, packaging and whitespace cleanup. It does not change playback/condition logic. The client
packages include their existing thirteen bundled libraries, exact upstream source
archives and license/notices. Optional server packages contain one companion JAR,
MIT license and server instructions; they contain no decoders or library/music data.

## Packaging and checkpoint

Both source archives and all four distribution packages pass their
contents audits: current metadata/notices, thirteen nested client libraries,
minimal scoped companion classes, bytecode targets and excluded local/test data.
Wrappers, build inputs and standalone Fabric writing/compiler inputs are present.
Client packages include exact dependency sources; server packages exclude client,
UI, audio, library and decoder classes/assets. Source archives exclude Git data,
caches, worlds, logs, personal backups, fixtures under ignored native workspaces
and old local copies. Historical version references remain unchanged.

Release source checkpoint: **`v1.1`**. Packages, four direct runtime JARs, two
source archives, a selection/installation guide and `SHA256SUMS.txt` are under
ignored **`outputs/1.1`**. Final runtime hashes identify the numbered artifacts; release preparation changed
no Java behavior. Both client
and companion metadata show 1.1. Generated UI screenshots were inspected, and all
temporary clients and servers exited after the checks.
Raw build/game logs and generated test state stay in ignored `work/release-1.1`.
No public upload, remote push or delivery to friends is part of this release.

The first NeoForge connection-client launch exited during native window startup,
before connection or probe assertions. Windows Application Error reported
`SDL3.dll` 3.4.14.0, exception `0xc000041d` (and an associated access violation).
There was no Java crash report. An unchanged retry started and connected, passing
the 12 companion-enabled checks and eight vanilla fallback checks. No AFMR code change was made for this incident;
the observed native module is recorded without claiming a root-cause diagnosis.
