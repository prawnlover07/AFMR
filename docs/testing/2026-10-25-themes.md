# Themes menu and sharing — October 25, 2026

Both maintained builds remain version 1.0.1. This feature received build-only
verification; Minecraft and the OS file picker were not opened.

## Implemented behavior

Display → Menus → Themes replaces the direct Menu colors entry. Named theme
snapshots include all ten menu colors, menu opacity, widget background RGB and
widget opacity. Graphite remains built in. Save as creates an independent named
copy. The editor previews valid values live, validates drafts and updates a
selected custom theme on save or page changes. The Graphite definition stays
immutable; customized current colors can be saved as a new theme.

Theme actions and right-click offer rename, export and confirmed deletion. Files
use .afmrt and contain only the five required appearance/name fields. Import adds
an independent ID/name without applying or replacing existing themes. Name
collisions receive a suffix. Saved themes are shared across profiles and included
in full backups. Fonts, images, blur, layout, music and playlists are excluded.
The collection is bounded at 128 custom themes.

Client-owned state and worker-owned file snapshots remain separate. One operation
runs at a time; reads are bounded at 64 KiB, and export replacement is atomic.
Parsing rejects missing/unknown/duplicate fields, bad RGB, malformed UTF-8,
non-numeric/non-finite/out-of-range opacity and trailing or lenient JSON content.
Explicit theme actions remain available during unrelated music scans.

## Reproduction

Run `build sourceZip` in each maintained project. `ColorThemeTest` and
`ThemeFilesTest` provide the focused regression cases. Fabric smoke helper
compilation uses `-Psmoke compileSmokeJava`; the root helper uses
`-p testing/native compileJava` after the runtime build.
