# Author-written UI copy workflow

Scope: NeoForge 26.3 and Fabric 1.20.1, version unchanged at 0.6.

This records the initial migration. The subsequent
[author-copy review](2026-10-23-author-copy.md) applies Animal's edits and adds
support for cleared paragraphs; the original nonempty-only rules below describe
the initial workflow's tested state.

`docs/UI-COPY.md` owns 156 editable passages: 142 shared, eight NeoForge-only
and six Fabric-only. Each has a screen/control heading, reference behavior,
target scope and explained placeholders. The editable paragraph is the sole
runtime source. Utility labels/states, errors, confirmations, diagnostics and
metadata remain unchanged. Existing key-binding translations moved unchanged
into shared `copy/utility-en_us.json`.

Both builds apply `gradle/ui-copy.gradle` to validate references and compile
native English language entries. It folds soft line breaks, retains paragraph
breaks, escapes ordinary percentages for Minecraft, and checks placeholders.
Tooltips use native `Component.translatable` calls. On-screen guidance is cached
at screen initialization where it is drawn repeatedly. No runtime Markdown
reader, background worker or extra authoring runtime was added. Column hover
copy moved from the Minecraft-independent model into `SongColumnsScreen`.

## Verification

- Both `build sourceZip` runs pass against the current combined source:
  **778 NeoForge / 788 Fabric JUnit tests**, zero failures/errors/skips.
- `testUiCopy` passes **19 compiler checks per target**: plain prose/Unicode,
  JSON round trips, paragraph folding, percentages, reordered placeholders,
  duplicate/missing/empty entries, invalid metadata/targets/markers, missing or
  repeated arguments, malformed placeholders, missing source references,
  unused entries, target restrictions and reserved utility keys.
- `validateUiCopy` verifies **150 NeoForge / 148 Fabric passages** against each
  target's actual Java call sites.
- A temporary windowless probe runs the generated resource through each
  Minecraft version's real `Language.loadFromJson` and `Component.translatable`.
  All **150 / 148 passages** reproduce the captured original wording exactly,
  substituting known sample arguments for the three dynamic templates. A further
  sample verifies quotes/apostrophes, Unicode, paragraphs, reordered arguments
  and literal percentages. This is language-formatting validation, not UI or audio.
- A captured pre-migration UI string inventory has no unexpected utility string
  removals. Both generated language resources exactly match the original copy
  inventory plus the unchanged 15 key-binding labels.
- Both source ZIPs contain the authoring document, compiler and utility language
  input. Their contents exclude Git/editor metadata, build/cache/run folders,
  local archives, complete backups, logs and Python caches.
- Both final JARs contain exactly one English language resource, identical to
  the applicable generated language output.
- Extracted the Fabric source ZIP into an isolated directory, changed one shared
  editable paragraph there, and ran `validateUiCopy testUiCopy generateUiCopy
  sourceZip` offline successfully. The edit (quotes, Unicode and a percentage)
  reached the generated resource; every other entry remained unchanged. The
  extracted build repackaged the edited writing file and shared inputs. This
  checks standalone authoring/resource generation and packaging, without
  repeating Java compilation in the extracted copy.

Commands used the local Java 25 toolchain and existing offline Gradle cache.
Initial incremental compilation attempts reported missing existing project
classes. Subsequent complete compilations (`options.incremental = false` through
a temporary init script), regression runs and builds passed; no persistent build
setting was changed for that investigation. Temporary verification scripts and
inventories live under ignored `work/`, outside the source packages.

Final visual/input limitations are tracked in `DEFERRED-TESTING.md`.

## Visual limits

No Minecraft window, personal profile, music file, foobar file, native picker or
system clipboard was used. Existing one-line guidance still truncates to its
available width; hover explanations use Minecraft's wrapping. Animal's rewritten
passages need a final visual/input/narration pass at the intended GUI scales.
