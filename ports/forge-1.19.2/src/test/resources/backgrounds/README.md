# Generated background fixtures

Generated by `testing/prepare_background_images.py` using Pillow. Inputs are solid
colors and rectangles; no external/player images. The generator copies identical
fixtures into the Fabric target and `--stage` copies only the WebP/GIF inputs to
the two existing disposable game profiles.

- `lossless.webp`: alpha, exact opaque colors and a transparent pixel; `lossy.webp`:
  constant RGB with a bounded decoding tolerance; `wide.webp`: 4096×1024 resizing.
- `animated.webp`: clean rejection of unsupported animation without replacement.
- `disposal.gif`: variable delays, transparency, partial patches and both restore
  disposal modes. `disposal-0.png` through `disposal-3.png` are independent Pillow
  composite outputs used as pixel-by-pixel decoding expectations.
- `bounded.gif`: 20 frames at 1024², requiring aggregate-memory resizing.
- `too-many.gif`: 513 tiny frames, requiring pre-decode rejection.
- `still.gif`: a single blue frame, normalized to PNG.

Fixtures are test resources only, excluded from the runtime mod JAR.
